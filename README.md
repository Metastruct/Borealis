# Borealis

Metastruct's shaderpack built for gm_construct_m3 but will *mostly* work on other maps, plus tod, the time of day, weather and season they're based on.

> 1) **If you add a new shader PLEASE COMMIT THE RELEVANT .hlsl!!!**
> 2) **Everything in this repo was read, corrected, researched and approved by a human (hi!!!), the ratio LLM/human coding is something like 50/50.**
